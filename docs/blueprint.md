# **App Name**: Espresso Admin

## Core Features:

- Login Page: Implements a login page with email/password inputs, validation, submit button with loading state, and a 'Forgot password' link, all within a fully centered responsive layout.
- Dashboard Overview: Creates a dashboard overview with stat cards (sales, orders, users, subscribers, top items), quick action buttons with icons, and a recent activity timeline, designed with a responsive sidebar and header layout.
- Orders Management: Develops an orders management section with an orders table (ID, customer, date, status, total, payment), a search/filter toolbar, row actions (view details, change status), and an order detail drawer/modal showing customer info, product list, and price breakdown.
- Menu Management: Builds a menu management interface for food and drinks, featuring a menu table with name, category, price, image, and status, along with category filters, search, and add/edit item forms that include inputs, dropdowns, file upload, and a toggle switch; optional category CRUD is also implemented.
- Merchandise Products: Constructs a merchandise products section with a product table showing name, price, stock, image, and category, and an add/edit product modal or page.
- Customer Management: Designs a customer management interface with a user table that includes ID, name, email, join date, order count, and total spent, enhanced with search functionality and a user detail drawer featuring avatar, info, history, and buttons for editing and deactivating users.
- CMS Pages: Assembles a set of CMS pages (Home, About, Contact, Privacy, and Terms) with modular components and features for dynamic content creation. The Home page features a Hero section, featured products, and custom CTA block; the About page includes a timeline (CRUD) and team members (CRUD); the Contact page has a form UI, a map, and contact details; static pages (Privacy, Terms) are editable with a rich text editor.

## Style Guidelines:

- Primary color: Deep Brown (#6F4E37) to evoke a sense of warmth and earthiness, reminiscent of rich coffee beans.
- Background color: Light Tan (#F5E7D2) provides a clean and inviting canvas, enhancing the overall readability and visual appeal of the dashboard.
- Accent color: Burnt Orange (#CC6633) is strategically used for interactive elements and highlights, drawing inspiration from the inviting warmth of coffee roasting.
- Font pairing: 'Poppins' (sans-serif) for headlines to provide a geometric and contemporary look, paired with 'PT Sans' (sans-serif) for body text to offer a balance of modernity and readability.
- Icons: Use a set of simple, modern icons from a library like Feather or Tabler Icons, with line weights that complement the typography.
- Responsive layout: A clean, component-based design with a collapsible sidebar, sticky header, and full mobile support for accessibility across devices.
- Subtle Transitions: Apply smooth Tailwind transitions and interactive states for hover, focus, and active elements, enhancing user engagement without being intrusive.
